## 1. サービスコンセプト

**「価格.com の 文化芸術支援版」**

複数の支援プラットフォームに分散している文化芸術プロジェクトを横断的に集約し、
トレンド・注目度・プラットフォーム比較を提供する。
支援者は A to B を起点に、自分に合った支援先を見つけて各プラットフォームで支援する。

---

## 2. 主要機能定義

### 機能 1: プロジェクト横断検索・一覧

```
[ユーザー]
    ↓ A to B にアクセス
[検索・フィルタ]
    - ジャンル（音楽/アート/映像/演劇/その他）
    - カテゴリ（インディー音楽/現代アート/舞台/etc）
    - 支援金額帯
    - プラットフォーム（CAMPFIRE / Bandcamp / ENjiNE / etc）
    - 残り日数
    - 達成率
    ↓
[プロジェクト一覧]
    - サムネイル / タイトル / アーティスト名
    - 現在の達成率・残り日数
    - 注目度スコア（ヒートスコア）
    - 出典プラットフォームのバッジ
```

### 機能 2: トレンド・ヒートスコア

**ヒートスコアとは:**
プロジェクトの「今の勢い・注目度」を数値化したもの。

| シグナル | 重み |
|---------|------|
| 過去24時間の支援者増加数 | 30% |
| 過去24時間の支援額増加 | 30% |
| SNS 言及数（X / Instagram） | 20% |
| 達成率の伸び速度 | 20% |

**表示形式:**
- 🔥🔥🔥（急上昇） / 🔥🔥（注目） / 🔥（じわ伸び）
- トップページに「今週の急上昇」「今日のピックアップ」セクション

### 機能 3: プラットフォーム比較

同じアーティスト・プロジェクトが複数プラットフォームにある場合、
または支援者が「どのプラットフォームで支援すべきか」を比較できる機能。

| 比較項目 |
|---------|
| プラットフォーム手数料（支援者負担 / プロジェクト負担） |
| 決済方法（クレカ / コンビニ / etc） |
| 特典の種類・内容 |
| 達成状況・残り日数 |
| 運営会社の信頼性スコア |

### 機能 4: ユーザー嗜好マッチング（Phase 2）

| ユーザーが設定できる嗜好 |
|------------------------|
| 好きなジャンル（複数選択） |
| 支援スタイル（少額多数 / まとめて一件 / 定期的） |
| 重視する価値観（発見重視 / 実績重視 / 地域応援 / etc） |
| 過去の支援履歴（任意連携） |

→ 嗜好に合ったプロジェクトを TOP に優先表示

### 機能 5: アーティスト・クリエイターページ

- アーティスト単位のプロフィールページ
- 複数プラットフォームでの活動を横断表示
- 過去プロジェクトの実績・達成率の履歴
- フォロー機能（新プロジェクト立ち上げ時に通知）

## 3. データ取得戦略

### Phase 1（MVP）: 手動 + 半自動

| 方法 | コスト | 件数 |
|------|-------|------|
| スタッフによる手動入力 | 時間コストのみ | 月20〜50件 |
| スクレイピング（公開データ） | 開発コスト小 | 自動化後は無制限 |

**スクレイピング対象プラットフォーム（Phase 1）:**
- CAMPFIRE（公開プロジェクトページ）
- Bandcamp（アーティスト・アルバムページ）
- ENjiNE

**注意:** 各プラットフォームの利用規約を確認の上、個人情報を含まない公開情報のみ取得。
必要に応じてパートナーシップ交渉に移行。

### Phase 2: API 連携 / パートナーシップ

- 公式 API の取得交渉（CAMPFIRE 等）
- プラットフォームとのデータ連携パートナー契約
- リアルタイムデータの精度向上

## 4. ページ構成（サイトマップ）

```
/ トップページ
├── /trending          トレンド・急上昇
├── /projects          プロジェクト一覧・検索
│   └── /projects/:id  プロジェクト詳細
├── /artists           アーティスト一覧
│   └── /artists/:id   アーティスト詳細
├── /platforms         プラットフォーム比較
│   └── /platforms/:id プラットフォーム詳細
├── /categories        ジャンル別一覧
│   ├── /music
│   ├── /art
│   └── /theater
└── /about             A to B について
```
