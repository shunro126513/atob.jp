# ミッション

**文化芸術分野の支援プロジェクトを横断的に集約・比較・可視化することで、
支援者と文化芸術の出会いを最大化する。**

## 私たちがすること

1. **集約** — CAMPFIRE / ENjiNE / Bandcamp 等、複数プラットフォームのプロジェクトを一元表示
2. **比較** — プラットフォームをまたいで、条件・手数料・特徴を比較できる
3. **トレンド可視化** — 「今注目されているプロジェクト」「急上昇中の支援者数」をリアルタイムで表示
4. **レコメンド** — ユーザーの嗜好・過去の行動をもとに、その人に合った支援先を表示

## 価値観

- **中立性** — 特定プラットフォームに肩入れせず、支援者の最善を考えた情報を提供する
- **透明性** — 手数料・実績・成果をわかりやすく開示する
- **発見の喜び** — 「こんなアーティストがいたのか」という体験を届ける
