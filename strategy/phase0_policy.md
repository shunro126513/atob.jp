# Phase 0 — 事業方針

**作成日:** 2026-05-31
**策定者:** CEO ミナミ（オーナー指示に基づく）

---

## Phase 0 の位置づけ

**個人プロジェクト / 情報提供サービスとして運営する**

| 項目 | 内容 |
|------|------|
| 法的形態 | 個人（開業届なし） |
| 収益 | なし（ボランティア運営） |
| データ収集 | 各プラットフォームの公開情報をスクレイピング |
| サービス性質 | 情報比較・集約（非商業） |
| 期間 | 事業として成立すると判断するまで |

---

## Phase 0 でやること

- スクレイピングで実データを集める
- サービスを公開して実際のユーザーに使ってもらう
- SNS でコンテンツを発信してフィードバックを集める
- サービスの価値検証を行う（「使いたい」と言ってもらえるか）

## Phase 0 でやらないこと

- 開業届の提出
- アフィリエイト申請・収益化
- 法人設立
- 外部への資金調達

---

## Phase 1 への移行条件（将来）

以下のいずれかを達成したとき、オーナーと協議の上で事業化に移行する:

| 条件 | 目安 |
|------|------|
| 月間ユニークユーザー | 5,000人以上 |
| 継続利用ユーザーの存在 | 月3回以上訪問するユーザーが確認できる |
| ユーザーからの「有料でも使いたい」声 | 複数件 |
| オーナーの意思決定 | オーナーが「事業として進める」と判断 |

移行時にやること:
1. 開業届の提出
2. CAMPFIRE 等アフィリエイトプログラムへの申請
3. プライバシーポリシー・利用規約の住所記載を更新
4. 事業用銀行口座の開設
