# ロードマップ — Phase 1: MVP（比較・集約プラットフォーム）

*更新日: 2026-05-31（ピボット後）*

## 目的

「比較・集約プラットフォーム」として最低限機能する MVP を低コストで立ち上げ、
ユーザーが実際にサイトを使って外部プラットフォームへ遷移するかを検証する。

---

## Phase 1a — MVP リリース（目標: 4〜6週間）

### 成果物

| 成果物 | 内容 |
|--------|------|
| Web サイト | Next.js + Vercel でデプロイ済みのサイト |
| プロジェクトDB | 20〜50件の手動入力済みプロジェクト |
| 検索・フィルタ | ジャンル / 達成率 / 残り日数 / プラットフォームで絞り込み可能 |
| トレンド表示 | 簡易ヒートスコア（達成率の伸び × 支援者数）を表示 |
| プラットフォーム比較 | 主要 3〜4 PF の基本情報比較ページ |

### タスク（優先順）

- [ ] Supabase DB スキーマ設計・構築
- [ ] 最初の20件プロジェクトデータ入力（手動）
- [ ] Next.js フロントエンド実装（一覧・検索・詳細）
- [ ] Vercel デプロイ + ドメイン設定
- [ ] CAMPFIRE アフィリエイトプログラム申請

---

## Phase 1b — 成長施策（MVP 後 1〜3ヶ月）

- メール会員登録機能の追加
- スクレイピングによるデータ自動更新（CAMPFIRE から）
- note / SNS での認知獲得開始
- 月間 PV 3,000 達成 → アフィリエイト収益が発生し始める

---

## Phase 2 への移行条件

- 月間ユニークユーザー 5,000 以上
- アフィリエイトによる月次収益が発生
- ユーザーからのフィードバックが20件以上集まる

---

## KPI（Phase 1）

| 指標 | 1ヶ月目 | 3ヶ月目 |
|------|--------|--------|
| 掲載プロジェクト数 | 20件 | 100件 |
| 月間 PV | 500 | 5,000 |
| CTR（外部PFへの遷移率） | - | 5%以上 |
| アフィリエイト収益 | 0円 | 1〜5万円 |
