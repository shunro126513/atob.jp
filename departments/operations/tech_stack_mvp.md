# MVP 技術スタック設計

**担当: CEO ミナミ**
*作成日: 2026-05-31*

---

## 1. 方針

- **低コスト優先**: 月額1万円以下で動かせる構成
- **スケール可能**: 将来の機能追加・自動化に耐えられる設計
- **スピード優先**: 最短でリリースできる選択をする
- **開発依存を最小化**: ノーコード/ローコードを活用し、技術的負債を作らない

---

## 2. 推奨技術スタック

### フロントエンド

| 役割 | 採用技術 | 理由 |
|------|---------|------|
| フレームワーク | **Next.js 14** | React ベース、SSG/SSR 対応、SEO に強い |
| スタイリング | **Tailwind CSS** | 高速開発、デザイン一貫性 |
| ホスティング | **Vercel（無料プラン）** | Next.js との相性最高、無料枠で十分 |

### バックエンド / データ

| 役割 | 採用技術 | 理由 |
|------|---------|------|
| データベース | **Supabase（無料プラン）** | PostgreSQL、無料枠500MB、認証機能付き |
| コンテンツ管理 | **Notion API** | 非エンジニアでもデータ入力できる |
| スクレイピング | **Python + GitHub Actions** | 無料で定期実行、CAMPFIRE 等から公開データ取得 |

### その他

| 役割 | 採用技術 | 理由 |
|------|---------|------|
| ドメイン | **Cloudflare** | 安価・DNS管理も一元化 |
| 解析 | **Vercel Analytics（無料）** | PV・クリック計測 |
| メール | **Resend（無料プラン）** | メルマガ・通知、月3,000通まで無料 |


## 5. MVP 開発ステップ

| ステップ | 内容 | 工数目安 |

| **合計** | | **約2〜3週間** |

## 6. 開発体制の判断

### 現状（Phase 1）

CEO ミナミが技術仕様を決定し、実装は以下で対応する：

| 作業 | 担当 |
|------|------|
| DB 設計・API 設計 | CEO ミナミ（設計のみ） |
| フロントエンド実装 | **外部フリーランス** or オーナーに技術リソースの確認 |
| スクレイピング | 同上 |
| コンテンツ入力・運用 | 社内（CMO ハルカ） |

### CTO の必要性

**Phase 1 では CTO は不要**。
以下の条件を満たした時点で採用を検討する：
- 月間 PV が 50,000 を超えた時
- API 自動連携・リアルタイムデータ処理が必要になった時
- 独自決済・会員機能の実装が必要になった時

> **CEO からオーナーへの確認事項:**
> MVP 実装のエンジニアリングリソースについて確認させてください。
> 外部フリーランスへの発注（概算: 30〜80万円）か、
> オーナー側に技術リソースがあるかをお聞きしたいです。
