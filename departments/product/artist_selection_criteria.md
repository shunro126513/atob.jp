# アーティスト・プロジェクト選定基準

**担当: CEO ミナミ**
*作成日: 2026-05-31*

---

## 1. 選定の基本方針

A to B が掲載するのは「今支援する意味があるアーティスト・プロジェクト」のみ。
誰でも載れないからこそ、掲載されること自体がアーティストの信頼担保になり、
支援者にとっての「見つけた喜び」にもなる。

**「今」という時間軸が重要。** 過去の実績より、今この瞬間に支援することで
アーティストの未来が変わる可能性が高いものを選ぶ。

---

## 2. 必須条件（全て満たすこと）

| 条件 | 詳細 |
|------|------|
| **制作中または直前** | すでに完成したものではなく、今まさに作っている or 作ろうとしている |
| **支援金の用途が明確** | 何に使うかを具体的に説明できる（「録音費用」「ツアー費用」等） |
| **成果物・体験が定義されている** | 支援の結果として何が生まれるかが明確（アルバム、ライブ、アート作品等） |
| **支援後の報告意志がある** | 完了後に A to B へ成果レポートを提出することに同意できる |
| **既存の支援/購入導線がある or 作れる** | CAMPFIRE / Bandcamp 等でプロジェクトを立ち上げられる |

---

## 3. 評価基準（スコアリング）

以下の5軸で評価し、合計 **15点以上** を掲載候補とする（25点満点）。

### ① アーティストのポテンシャル（0〜5点）

| 点数 | 基準 |
|------|------|
| 5 | 突出した才能・独自性がある。音楽・表現に聴く者/見る者を動かす力がある |
| 3 | 実力は確かで個性もある。まだ広く知られていないだけ |
| 1 | 基礎技術はあるが、個性・独自性が見えにくい |
| 0 | 技術・独自性ともに不十分 |

### ② 「今支援する意味」の明確さ（0〜5点）

| 点数 | 基準 |
|------|------|
| 5 | このタイミングを逃すと実現しない、という緊迫感がある |
| 3 | 今支援することで何かが変わることがわかる |
| 1 | 支援はありがたいが、今でなくてもいい |
| 0 | タイミングが不明確 |

### ③ ストーリーの共感度（0〜5点）

| 点数 | 基準 |
|------|------|
| 5 | 聴いた（読んだ）だけで応援したくなる強いストーリーがある |
| 3 | 人柄・背景が伝わり、関心を持てる |
| 1 | 活動内容はわかるがストーリーが見えにくい |
| 0 | 感情的なつながりが作れない |

### ④ 支援体験・特典の質（0〜5点）

| 点数 | 基準 |
|------|------|
| 5 | 支援者にとっての体験・特典が魅力的で独自性がある |
| 3 | 標準的な特典あり（音源提供・クレジット掲載等） |
| 1 | 特典が薄い or ない |
| 0 | 支援者への還元が全くない |

### ⑤ 信頼性・実現可能性（0〜5点）

| 点数 | 基準 |
|------|------|
| 5 | 過去の実績 + 具体的な計画があり、確実に実現できると判断できる |
| 3 | 実績は少ないが計画が明確。リスクは低い |
| 1 | 計画があいまい、または実績がなく不確実性が高い |
| 0 | 実現可能性に重大な懸念がある |

---

## 4. 掲載除外条件（いずれか一つでも該当したら除外）

- すでに大手レーベルと契約しており、資金面で十分な支援を受けている
- 政治的・宗教的な主張が前面に出ている
- 支援金の用途が不透明 or 開示を拒否している
- 過去に支援者への未履行が判明している
- A to B のブランドと明らかに不整合なコンテンツ（暴力的・差別的等）

---

## 5. 選定フロー

```
候補アーティスト発見
        ↓
スコアリング（5軸 × 5点）
        ↓
15点以上 → 詳細ヒアリング（用途・計画・特典の確認）
        ↓
合意書締結（掲載・手数料・報告義務）
        ↓
コンテンツ制作（記事・写真）
        ↓
掲載・公開
```

---

## 6. 最初に狙うジャンル・フェーズ

| 分類 | 詳細 |
|------|------|
| ジャンル | インディーポップ / フォーク / ジャズ / 実験音楽（最初の3ヶ月） |
| キャリアフェーズ | インディーズデビュー前後〜メジャー手前（「まだ知られていない逸材」が最適） |
| 支援目標額 | 30〜200万円（大きすぎると達成ハードルが上がる） |
| 居住地 | 首都圏・関西圏中心（初期はリアルコンタクトも必要なため） |
