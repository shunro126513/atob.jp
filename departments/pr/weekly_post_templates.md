## リール動画 — 撮影・制作チェックリスト

（毎週1本制作を目標）

**制作前**
- [ ] 今週のヒートTop3から1件を選定
- [ ] プロジェクトの公式画像・動画を収集（引用・クレジット前提）
- [ ] 30〜45秒のスクリプトを作成
- [ ] BGM選定（フリー素材 or アーティストの楽曲で許可取得）

**制作**
- [ ] CapCut / Canva Video で編集
- [ ] テキストオーバーレイ: プロジェクト名・達成率・残り日数
- [ ] エンドカード: 「AtoB.jp でチェック」
- [ ] 字幕を入れる（音声オフで見る人向け）

**公開**
- [ ] Instagram Reels にアップ
- [ ] 同時に TikTok にもアップ（Month 2〜）
- [ ] X にも動画投稿
- [ ] パフォーマンスを1週間後に記録
