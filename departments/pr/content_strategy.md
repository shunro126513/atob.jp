# コンテンツ戦略 — 既存成功モデル研究に基づく A to B 版

**担当:** PR ナナ / CMO ハルカ
**作成日:** 2026-05-31

---

## 1. 成功事例から学んだこと

### Kickstarter の SNS 戦略（海外最大手 CF）

| 手法 | 学べること | A to B への応用 |
|------|-----------|---------------|
| 「Just Funded」投稿 | 達成の瞬間にリツイートが爆発的に増える | ヒートスコア急上昇プロジェクトを即発信 |
| プロジェクト動画の再投稿 | クリエイターのコンテンツを使ってリーチ拡大 | アーティストの公式素材を引用 RT |
| コメント欄でのアーティスト応援 | コミュニティ感を演出 | 支援者・アーティスト両方に積極的にリプライ |

### CAMPFIRE の SNS 戦略（国内最大手）

| 手法 | 学べること | A to B への応用 |
|------|-----------|---------------|
| 週1「注目プロジェクト」メルマガ | 定期的な接点がリピーターを作る | 「今週のヒートTop5」を毎週月曜に投稿 |
| カテゴリ別の特集 | セグメントごとのファンを取り込む | ジャンル別ハッシュタグで週テーマを設定 |

### 価格.com の SEO・コンテンツ戦略（比較サービスの雄）

| 手法 | 学べること | A to B への応用 |
|------|-----------|---------------|
| 「○○ vs ○○」比較記事 | 検索意図と完全一致でSEO強い | note に「CAMPFIRE vs READYFOR」系記事 |
| ランキング形式コンテンツ | 保存・シェアされやすい | 「達成率ランキング」「ヒートTop10」 |
| 数字・データの可視化 | 信頼性と拡散性が上がる | グラフ・インフォグラフィックで表現 |

### ほぼ日刊イトイ新聞の文化的コンテンツ戦略

| 手法 | 学べること | A to B への応用 |
|------|-----------|---------------|
| 「買う」より「参加する」文脈 | 消費者をコミュニティメンバーとして扱う | 「支援者」ではなく「参加者」として語る |
| 作り手の物語を深掘り | エモーショナルな繋がりを生む | アーティストストーリー特集 |

## 2. A to B のコンテンツフォーマット一覧

### 【フォーマット A】ヒート速報（X・Instagram Stories・TikTok）

```
🔥 ヒートスコア急上昇！

[アーティスト名]の[プロジェクトタイトル]
達成率: ●●% → ●●%（24時間で+●%！）
支援者: ●●人
残り: ●日

🔗 AtoB.jp で詳細を確認 →
#クラファン #文化芸術 #[ジャンル]
```
**投稿タイミング:** 達成率が10%以上急上昇したとき（週1〜3回）

---

### 【フォーマット B】週間ヒートランキング（X・Instagram Feed・note）

```
📊 今週の文化芸術クラファン ヒートTop5

1位🔥 [タイトル] — ●●% 達成（[PF名]）
2位🔥 [タイトル] — ●●% 達成
3位🔥 [タイトル] — ●●% 達成
4位🌟 [タイトル] — ●●% 達成
5位🌟 [タイトル] — ●●% 達成

詳しくはプロフィールリンクから
#AtoB #クラファン #文化芸術
```
**投稿タイミング:** 毎週月曜日 12:00（昼休みに見られるように）

---

### 【フォーマット C】プラットフォーム比較インフォグラフィック（Instagram Feed・保存促進）

内容例:
- 「CAMPFIRE vs READYFOR: 手数料・ジャンル・特徴を比較」
- 「音楽プロジェクトに最適なクラファンPFはどこ？」
- 「文化芸術支援 3サービスの違い」

**設計:**
- 縦長(1080×1350px)のカルーセル形式（スワイプで比較できる）
- 1枚目: 「どれがいい？」という問いかけで興味を引く
- 2〜4枚目: 項目別比較
- 最終枚: 「AtoB.jp でも見られます」CTA

---

### 【フォーマット D】リール動画（Instagram Reels・TikTok）

**動画 Type 1 — 「今週の注目プロジェクト」（30秒）**

```
[0:00-0:03] フック
「このプロジェクト、24時間で100万円集まったって知ってた？」
テキストオーバーレイ + BGM

[0:04-0:15] プロジェクト紹介
・アーティスト名 + ジャンル
・プロジェクトのビジュアル（画像スライド）
・目標・達成率・残り日数のテキスト

[0:16-0:24] ヒートスコアの説明
「A to B ではこの"熱量"をヒートスコアで可視化してます 🔥」

[0:25-0:30] CTA
「チェックはプロフィールリンクから」
```

**動画 Type 2 — 「プラットフォーム比較」（45秒）**

```
[0:00-0:05] フック
「クラファンのサービス、どれがいいか迷ったことある？」

[0:06-0:30] 各PFの特徴を3〜4個テンポよく紹介
・CAMPFIRE: 国内最大、幅広いジャンル
・READYFOR: 文化芸術・社会課題
・Bandcamp: 音楽特化、海外にも届く

[0:31-0:45] CTA
「A to B ではすべて一括比較できます」
```

**動画 Type 3 — 「アーティストストーリー」（60秒）**

```
[0:00-0:10] 感情フック
「このアーティスト、デビュー10年で初めてクラファンに挑戦した理由」

[0:11-0:45] ストーリー紹介（テキスト + プロジェクト画像）
・背景・動機
・どんな作品を作ろうとしているか
・現在の達成状況

[0:46-0:60] 共感 + CTA
「支援したい方は AtoB.jp で詳細をチェック 🎵」
```

### 【フォーマット E】note 長文記事（SEO + ブランド構築）

| 記事タイプ | 例 | 目的 |
|-----------|-----|------|
| プラットフォーム比較 | 「CAMPFIRE vs READYFOR: 文化芸術プロジェクトに最適なのは？」 | SEO流入 |

| ハウツー | 「クラファンで好きなアーティストを支援する前に読む5つのこと」 | 初心者流入 |

## 3. コンテンツ制作フロー

```
1. サイトのヒートスコアを確認（週次）
   ↓
2. 上位プロジェクトをピックアップ
   ↓
3. フォーマットを選択（A〜E）
   ↓
4. 投稿文 / スクリプト作成
   ↓
5. CEO ミナミに確認（炎上リスク・事実確認）
   ↓
6. 発信 + 反応モニタリング
   ↓
7. 週次レポートにまとめ
```
