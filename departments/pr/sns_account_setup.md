## 3. アカウント開設手順（オーナーへ）

以下の順番でオーナーに開設をお願いします。
開設後、アカウント情報（ID・パスワード）を CEO ミナミに共有してください。

```
1. X（Twitter）
   → twitter.com/i/flow/signup
   → ユーザー名: AtoB_jp
   → メール: info@atob.jp（または業務用メール）

2. Instagram
   → instagram.com/accounts/emailsignup
   → ユーザー名: atob.jp
   → ビジネスアカウントに切り替え（設定 → プロアカウント）

3. note
   → note.com/signup
   → ユーザー名: atob
   → クリエイター設定でメディア登録
```
