## Instagram 運用方針

### ポジショニング
「文化芸術の熱量を視覚化するメディア」。
リール動画とカルーセル投稿でリーチを拡大。

### 投稿比率
- リール（Reels）: 40%
- カルーセル（複数枚）: 40%
- 単枚フィード: 10%
- ストーリーズ: 毎日

### リール投稿フォーマット（3種）

**リールA — ヒート速報（30秒）**

シーン構成:
```
[0:00-0:04] フック（テキストオーバーレイ）
  「このプロジェクト、48時間で●万円集めた」
  BGM: 明るいアップテンポのフリー楽曲

[0:05-0:18] プロジェクト紹介
  画像スライド（プロジェクト画像 + 数字テキスト）
  テキスト:「[タイトル]」[ジャンル]
  達成率●% / 支援者●人 / 残り●日

[0:19-0:25] A to B での位置づけ
  「ヒートスコア: ●🔥」
  「複数PFから横断検索できます」

[0:26-0:30] CTA
  「atob.jp でチェック」（テキスト）
  「プロフィールリンクから →」
```

**リールB — PF比較（45秒）**

シーン構成:
```
[0:00-0:06] フック
  「クラファン、どのサービスがいいか知ってる？」

[0:07-0:35] 3サービスを順番に紹介
  各サービス 8〜10秒
  ・サービス名
  ・手数料
  ・対応ジャンルの特徴
  ・一言コメント

[0:36-0:45] CTA
  「A to B でさらに詳しく比較できます」
  「atob.jp/compare」
```

**リールC — 応援スコア告知（30秒）**

シーン構成:
```
[0:00-0:05] フック
  「支援しなくても、応援できる」

[0:06-0:20] 機能説明
  「A to B の「応援ボタン」」
  「1日1回、気になるプロジェクトに応援を送れます」
  「応援が多いプロジェクトは ヒートスコアが上がります」

[0:21-0:30] CTA
  「今日も誰かのプロジェクトを応援しよう 🔥」
  「atob.jp」
```

### カルーセル投稿フォーマット（2種）

**カルーセルA — 週間ヒートランキング**
- 1枚目: 「今週の文化芸術クラファン ヒートTop5」タイトル
- 2〜6枚目: 各プロジェクト1件ずつ（順位・タイトル・達成率・ヒート・PF名）
- 7枚目: 「A to B で全プロジェクトをチェック」CTA

**カルーセルB — PF比較インフォグラフィック**
- 1枚目: 「どのクラファンPFがいい？」問いかけ
- 2〜4枚目: 各PFの特徴（1枚1サービス）
- 5枚目: まとめ比較表
- 6枚目: 「atob.jp/compare で全項目を比較」CTA

## ハッシュタグ戦略

### X（毎投稿必ず含める）
```
固定: #クラファン #文化芸術 #AtoB
ジャンル別（追加）: #音楽 / #アート / #映像 / #演劇 / #ダンス
```

