## 1. ブランドの核心

| 要素 | 内容 |
|------|------|
| **ブランドスローガン** | 支援ではなく、参加。 |
| **ブランドパーソナリティ** | 知的・誠実・熱狂的・身近 |
| **ブランドの約束** | 文化芸術の熱量を可視化し、支援者と創り手をつなぐ |

**ブランドボイス（文章のトーン）:**
- 簡潔・断定的（「〜かもしれません」ではなく「〜です」）
- 専門的すぎない（一般ユーザーが読める）
- 文化・芸術への敬意を持った表現
- 数字を使って具体性を出す

## 4. ロゴ方針（AI 生成前の設計）

### コンセプト案 A — タイポグラフィロゴ

```
┌──────────────────────┐
│                      │
│   A → B              │
│   ──────             │
│   文化芸術比較        │
│                      │
└──────────────────────┘
```
- 矢印（→）がArtist/Art から Backer/Benefactor への"つながり"を象徴
- シンプル・覚えやすい
- 色: Brand Purple

### コンセプト案 B — アイコン + テキスト

```
┌──────────────────────┐
│                      │
│   ◈  A to B          │
│      ──────          │
│      文化芸術支援     │
│                      │
└──────────────────────┘
```
- ◈（ダイヤ形）= 価値・宝・アートの象徴
- テキストとの組み合わせ

### AI 生成プロンプト（Canva / Ideogram 向け）

```
Logo design for "A to B", a Japanese cultural arts crowdfunding 
comparison platform. Clean, modern, minimal. Purple (#9333ea) 
as primary color. Show an arrow or connection between A and B 
to symbolize artist-to-backer journey. Sans-serif typography. 
White background. Professional SaaS aesthetic.
```

## 5. ビジュアルスタイル

### 写真・画像
- 実際のアーティスト・クリエイターの写真（許可を得たもの）
- ステージ・制作現場・パフォーマンスシーンを優先
- 白背景の商品写真は避ける（温かみが出ない）

### アイコン
- Lucide Icons / Heroicons（すでに Next.js で対応しやすい）
- アウトラインスタイル統一

### カードデザイン
- 角丸: 12px（rounded-xl）
- シャドウ: 軽い（shadow-sm）
- ホバー: shadow-md に変化

---

## 6. NGデザイン

- 過度なグラデーション（安っぽく見える）
- 赤色の多用（ヒートスコア専用）
- 5色以上の多色使い
- 明朝体の使用（ブランドイメージと合わない）
