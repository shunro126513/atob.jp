## X（Twitter） {#x-twitter}

### Step 1 — アカウント作成

1. https://twitter.com/i/flow/signup を開く
2. 「アカウントを作成」をクリック
3. 以下を入力:
   ```
   名前: A to B
   メール: （業務用メールアドレス）
   生年月日: 任意
   ```
4. SMS 認証 or メール認証を完了

### Step 2 — ユーザー名の設定

アカウント作成後、設定からユーザー名を変更:
```
希望ユーザー名: AtoB_jp
取れない場合: AtoB_official / AtoB_info
```
「設定とサポート」→「設定とプライバシー」→「アカウント」→「ユーザー名」

### Step 3 — プロフィール設定

**プロフィール画像:** ロゴ完成後に設定（それまでは文字のみでも可）

**プロフィール文（コピペ用）:**
```
文化芸術プロジェクトを横断比較 🎵🎨🎬
音楽・アート・映像・演劇のクラファンをヒートスコアで可視化
CAMPFIRE・Bandcamp・ENjiNEなど複数PFを一括検索 | AtoB.jp
```

**場所:**
```
日本
```

**ウェブサイト:**
```
https://atob.jp （ドメイン取得後に設定）
```

### Step 4 — 固定ツイートの投稿（アカウント作成直後）

```
🎉 A to B の公式Xアカウントを開設しました。

文化芸術のクラウドファンディングプロジェクトを、
複数のプラットフォームから横断検索・比較できるサービスを準備中です。

音楽・アート・映像・演劇・ダンス — あらゆる文化芸術への「参加」を、もっと簡単に。

近日公開予定です。フォローをお願いします 🙏

#クラファン #文化芸術 #音楽 #アート
```

## Instagram {#instagram}

### Step 1 — アカウント作成

1. https://www.instagram.com/accounts/emailsignup を開く
2. 以下を入力:
   ```
   メール: （業務用メールアドレス）
   名前: A to B
   ユーザー名: atob.jp
   パスワード: （安全なパスワード）
   ```
3. メール認証を完了

### Step 2 — プロアカウントに切り替え（重要）

1. プロフィール画面 → 右上「≡」→「設定とプライバシー」
2. 「アカウントの種類とツール」
3. 「プロアカウントに切り替える」
4. 種別:「**クリエイター**」を選択
5. カテゴリ:「**メディア/ニュース**」

→ これをすることでインサイト（閲覧数・リーチ）が見られるようになります

### Step 3 — プロフィール設定

**プロフィール文（コピペ用・最大150字）:**
```
支援ではなく、参加。🎨
文化芸術のクラファンを横断比較📊
音楽🎵・アート🎨・映像🎬・演劇🎭
CAMPFIRE / Bandcamp / ENjiNE etc.
▼ プロジェクトを探す
```

**ウェブサイト:**
```
https://atob.jp （ドメイン取得後に設定）
```

### Step 4 — ハイライト（フォルダ）作成

アカウント作成後、以下の名前でハイライトフォルダを作っておく:
```
📊 ヒートランキング
🔍 使い方
⚖️ PF比較
🎵 注目PJ
```

## note {#note}

### Step 1 — アカウント作成

1. https://note.com/signup を開く
2. 以下を入力:
   ```
   メール: （業務用メールアドレス）
   パスワード: （安全なパスワード）
   ユーザー名: atob
   ```
3. メール認証を完了

### Step 2 — プロフィール設定

**表示名:**
```
A to B
```

**プロフィール文（コピペ用）:**
```
文化芸術支援プロジェクトの比較・集約プラットフォーム「A to B」の公式ノートです。

CAMPFIRE・Bandcamp・ENjiNEなど複数のクラウドファンディングプラットフォームの
文化芸術プロジェクトを横断検索・比較できるサービスを準備中。

音楽・アート・映像・演劇・ダンス。
あらゆる文化芸術への「参加」をもっと簡単に。

🔗 atob.jp（準備中）
```

### Step 3 — マガジン作成

プロフィール → 「マガジンを作る」:
```
マガジン名: 文化芸術×支援の現場から
説明: クラウドファンディングプラットフォームの比較・活用方法・注目プロジェクトの紹介
```

### Step 4 — 最初の記事を公開

記事ドラフトは `departments/marketing/note_article_01_draft.md` にあります。
内容を確認して問題なければ、そのまま note に貼り付けて公開してください。

## SNS と CEO ミナミの連携方法

### アカウント作成後の引き継ぎ手順

SNS アカウントを作成したら、以下を CEO ミナミ（このチャット）に共有してください:

```
X: @[ユーザー名]
Instagram: @[ユーザー名]
note: [URL]
```

→ これ以降、PR ナナが毎週投稿コンテンツを準備して、
  このプロジェクトフォルダ（`departments/pr/`）に格納します。
  オーナーはそのテキストをコピペして投稿するだけです。

### 投稿の流れ（毎週）

```
月曜日:
  PR ナナが「今週の投稿セット」を準備
  → departments/pr/posts/YYYY-WW.md に格納
  
オーナーがやること:
  → そのファイルを開いて、各投稿をコピーして各SNSに貼り付ける
  → 所要時間: 週 10〜15分
```
